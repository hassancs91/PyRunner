How plugins use storage

A plugin reads and writes through the SDK, confined to its own prefix:

from core.plugins.api import StorageAPI

storage = StorageAPI(OWNER)  # confined to apps/<your-plugin>/
storage.put("avatars/abc.jpg", data, content_type="image/jpeg")
url = storage.url("avatars/abc.jpg")

Pick an assets connection above to enable it — keep it separate from the backup bucket, which should stay private. Without a public base URL, url() returns a presigned link that expires.

How to use in a script

Install claude-agent-sdk in the script's Environment, then:

from pyrunner_ai import ask_claude

answer = ask_claude("Search the web for today's AI news and summarize it")
print(answer)

Scripts always use the active provider. Web search/fetch tools are available on Anthropic only; other providers still support your own tools and plain prompts.

For an Anthropic subscription token, run claude setup-token on your own machine (logged into Claude) and paste the token it prints (starts with sk-ant-oat01-) — not the browser authorization code.

How it works

A secret with source External provider stores only a reference (e.g. kv/myapp#API_KEY). Its value is fetched from the provider when a run starts, injected and masked exactly like a stored secret, and cached in-process for the provider's TTL.

If a fetch fails, the run fails before it starts (fail-closed) — unless the provider's on-error is set to serve the last cached value. Rotate a value in the provider and the next run past the TTL picks it up.

How collections use a provider

A collection pins the provider's model and the dimension recorded by Test when it is created. Changing the model later resets the dimension and means a new collection — the vector space never changes under existing points. Usage (tokens, calls) is counted on the provider and on each collection.
