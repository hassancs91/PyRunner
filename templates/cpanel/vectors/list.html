Using collections

Each collection is a named set of points (a vector, a JSON payload and optionally the source text) with a pinned embedding model and dimension. The Local store keeps one SQLite file per collection on the data volume and searches it exactly — comfortable up to ~{{ soft_limit }} points. Scripts and plugins open collections by name through the pyrunner_vectors helper and the plugin SDK (arriving in the next stage); the Brain and the RAG plugin build on the same seam.
